# Business Recommendations - tie each one to a finding

Write a recommendation ONLY if the matching finding is confirmed in your data. Delete rows that don't apply.
Recommendations are hypotheses to A/B test; this dataset cannot prove an action will work.

| If your data shows... | Recommendation | Target segment (from q11/q12) | Success metric | Evidence (query + numbers) |
|---|---|---|---|---|
| Month-to-month churn far above long-term churn | Offer a discount/perk to move high-risk month-to-month customers to a 1-year contract | | Offer conversion rate; churn of converted vs not | |
| Churn concentrated in first months | Structured onboarding: welcome contact and set-up check in the first 30-90 days | | Churn within first 12 months | |
| Tech Support / more add-ons linked to lower churn | Trial or bundle add-ons (e.g. Tech Support) for low-attachment customers | | Churn of trial vs control group | |
| One internet type churns more even within contract | Investigate service quality and pricing for that product; review reasons in q15 | | Complaint themes; churn after fixes | |
| A payment method churns more even within contract | Incentivise automatic payment (small credit) | | Auto-pay adoption; churn change | |
| High-bill customers churn more (within contract) | Loyalty pricing or plan review before renewal | | Churn in top charge band | |
| Competitor / price reasons dominate | Competitive price benchmarking; win-back offers | | Win-back rate | |
| Risk rule shows meaningful lift (q16) | Proactive outreach to the q12 call list, ordered by monthly charges | | Save rate vs untreated customers | |

Prioritisation: rank by (revenue at risk) x (expected save rate) / (cost of the action). State assumptions for save rate and cost clearly.
